MySQL Terminal Commands:

To see the tables in a local MySQL database directly from your Mac Terminal, use the following one-line command:

mysql -u root -p -e "USE your_database_name; SHOW TABLES;"
mysql -u root -p -e "USE my_app_dev; SHOW TABLES;"

(Replace your_database_name with the actual name of your database, and change root if you use a different MySQL username.)
Step-by-Step Methods
You can achieve this either by running a quick single command or by logging into the interactive MySQL shell.
Method 1: The Quick One-Liner (No Shell Login)
This executes the query from your Mac terminal and immediately returns you to the normal terminal prompt: [1]
1.	Open your Terminal app.
2.	Run the command:

mysql -u root -p -e "SHOW TABLES FROM your_database_name;"

3.	Type your MySQL password when prompted and press Enter.
Method 2: Inside the Interactive MySQL Shell
If you prefer to browse your database interactively: [1]
1.	Log in to your local MySQL server:

mysql -u root -p

2.	Enter your password. Your prompt will change to mysql>.
3.	View available databases to find the right one:

SHOW DATABASES;

4.	Select your database:
USE your_database_name;
USE my_app_dev;

5.	List all tables in that database:

SHOW TABLES;

6.	Type exit or quit to leave the shell
